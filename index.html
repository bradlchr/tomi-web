Google Sign-In & Sync Setup

Tomi Web synchronizes with the Android native app via your private Google Drive AppData folder (tomi_cloud_sync.json).

Quick Setup Guide:
1. Open Google Cloud Console Credentials.
2. Click Create Credentials → OAuth client ID.
3. Choose Application Type: Web application.
4. Under Authorized JavaScript origins, add:
  • https://bradlchr.github.io
  • http://localhost:8080 (for local testing)
5. In Enabled APIs, make sure Google Drive API is enabled.
6. Paste your Web Client ID below.
